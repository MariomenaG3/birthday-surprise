# مفاجأة عيد ميلاد حبيبيتي 🎂

موقع بسيط من 3 صفحات:

1. `index.html` — صفحة الديكور (بالونات وقلوب)
2. `message.html` — صفحة الكلمات اللي كتبتها ليها
3. `surprise.html` — صفحة الفيديو والصور مع الأغنية

## اللي محتاج ت تعملاه:

### 1. ضعي الفيديو والأغنية
- ضعي ملف الفيديو باسم `our-video.mp4` في نفس المجلد، أو غيري اسم الملف في `surprise.html`.
- ضعي ملف الأغنية باسم `our-song.mp3` في نفس المجلد، أو غيريasename في `surprise.html`.
- لو عايزة تضيفي صور، ممكن تستبدلي `<video>` بصور باستخدام `<img src="photo1.jpg">` إلخ.

### 2. عدل الكلمات
 افتحي `message.html` واكتي الرسائل اللي عايزة تقوليها ليها في صندوق `.message-text`.

### 3. Raising the link (إتاحته على الإنترنت)
أبسط طريقة مجاناً:

**Netlify Drop (أسرع):**
1. ادخلي على [netlify.com/drop](https://app.netlify.com/drop)
2. اسحبي مجلد `birthday-surprise` كله وأسقطيه في الصفحة.
3. هيعطيك لينك مباشر تبعتي ليا لحبيبتك.

**GitHub Pages:**
1. أنشئ مستودع (Repository) جديد على GitHub.
2. raised الملفات فيه.
3. من الإعدادات (Settings) → Pages،اختري الفرع `main` و سيبjuh.
4. هيعطيك لينك مثل `https://username.github.io/repo-name/`.
